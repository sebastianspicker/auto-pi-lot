Agents propose. The reducer decides.

Each trace is a scripted host sending events to the real run reducer from @auto-pi-lot/core. Step through a run to see which events the reducer applies, which it rejects, and what it tells the host to do next. Nothing on this page calls a model.

Early foundation. The deterministic core is built and tested. Running real tasks end to end is not built yet.
