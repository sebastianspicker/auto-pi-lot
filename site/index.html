auto-pi-lot / run traces

source design roadmap

These are recorded runs of the reducer in @auto-pi-lot/core, the part of auto-pi-lot that decides what happens next in a run. A test script plays the host and sends it events. Each line below is one event and what the reducer did with it. When it rejects an event, it gives a reason and nothing changes. No AI model is involved.

Only this core exists so far. Saving state, running workers and the /graph on command aren't built yet, so none of these runs did real work.
